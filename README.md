# holoSticker_AEhack

After Effects 用スクリプト。アクティブなコンポジション内に、ホログラム風のタイルステッカー(`holoSticker_001`)を自動生成します。回転させると光の反射(色収差付きライトスイープ)が動く、いわゆる「ホロシール」風のエフェクトを、手動操作なしでワンクリックで組み立てます。

## できること

1. アクティブなコンポジション内に新規コンポ `holoSticker_001` を作成してレイヤーとして配置(幅・高さはUIで指定、既定 1080×1080)
2. その中に正方形タイル `tile_001` を1枚作成し、グレー2枚・ノイズ・ブロックディゾルブでベースの質感を作成
3. CC Light SweepとShift Channelsで疑似的な色収差(R/G/B)のライトスイープを作成し、放射状ブラーを適用
4. Particle Playgroundで `tile_001` をコンポ全面に隙間なく敷き詰め
5. `holoSticker_001` の回転(X/Y/Z Rotation・Orientation・親のワールド回転・アクティブカメラの動き・手動角度コントロール)をすべて合成し、タイル内のライトスイープの角度に反映するエクスプレッションを設定
6. 生成物はすべて `holoSticker_00N` フォルダ(直下はメインコンポのみ、それ以外は `Source_00N` サブフォルダ)に自動整理
7. タイムラインからレイヤーを削除すると自動監視が検知し、確認の上でProject内の関連アイテム・フォルダも削除

日本語 / English のUI表記に対応しています。

## 使い方

1. After Effectsで、`holoSticker_001` を配置したいコンポジションを開いてアクティブにする
2. `ファイル > スクリプト > スクリプトファイルを実行` (`File > Scripts > Run Script File...`) から `holoSticker_AEhack.jsx` を選択
3. ダイアログで幅・高さ・タイルの数(1辺あたり)を指定し、「作成 / Create」を押す
4. もう1個作りたい場合は、スクリプトを再度実行する(`holoSticker_001`, `_002`, `_003`... と自動採番)

## 動作要件

- Adobe After Effects(ExtendScript / `.jsx` 実行環境があるバージョン)
- 実行前に、配置先となるコンポジションをアクティブにしておくこと(無い場合はエラーで終了)

## 既知の制約

- 親子付け(`parent`)そのものをスクリプトから付け外しした直後は、AEのエクスプレッションエンジン側のキャッシュにより `toWorldVec()` の値が即座に更新されないことがあります。タイムラインを少しスクラブ(再生ヘッドを動かす)すると解消します。
- タイムラインからのレイヤー削除検知は `app.scheduleTask` によるポーリング(2秒間隔)のため、検知に最大2秒程度のタイムラグがあります。
- 監視はAEセッション内のみ有効です。AEを再起動すると監視は解除されます(その後 `holoSticker_AEhack` で新規に1個作成すると監視ループが自動的に再起動します。既存の `holoSticker` は再登録されません)。

## 開発メモ・デバッグ履歴

このスクリプトは実機検証を重ねながら開発されており、発見された不具合とその対処はスクリプト本体(`holoSticker_AEhack.jsx`)冒頭のコメントに詳細に記録されています。主なもの:

- コンポ/レイヤーの特定を名前文字列の再検索ではなく、オブジェクト参照(またはprecomposeの戻り値)で行うように統一(AEは同名アイテムの重複を許すため)
- アクティブコンポの取得を「作成」ボタンクリック時点に変更(パネル常駐時の取り違えバグ対策)
- Particle Playgroundの格子計算を `Math.ceil` + タイル実寸の整数倍に変更し、コンポサイズとタイル数の組み合わせによらず隙間なく敷き詰められるように修正
- 3D/2Dレイヤー切り替え時の回転連動判定を、`threeDLayer` プロパティ(エクスプレッション内では常に `undefined` になる既知の癖がある)ではなく `toWorldVec()` の配列長で判定するように修正
- カメラの視線ベクトル・sticker自身のワールド回転をそれぞれ `toWorldVec()` で取得し、sticker回転とカメラの動きを二重カウントしないように分離
- レイヤー削除→再追加でエクスプレッションが `Expression Disabled` のまま復活しない問題を、`try/catch` で例外を発生させない実装に変更して解消
- 空になった既定の `Solids` フォルダを整理時に自動削除

### 今回のリリース時の確認事項

- スクリプト全体の構文チェック(JavaScriptとしての構文エラーの有無)を実施し、問題なし
- 関数定義の重複や未解決の `TODO` / `FIXME` が無いことを確認
- 括弧・波括弧・角括弧の対応に不整合が無いことを確認

ExtendScriptの実行にはAdobe After Effects本体が必要なため、実機上での最終確認(実際にコンポを生成し、回転・カメラ連動・自動監視が動作すること)は、配布後にAE上で実行してご確認ください。
